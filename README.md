# TeamPass downloads

Installers for [TeamPass](https://teampass.au) — share your team's tool logins without sharing passwords.

Download from **[teampass.au/download](https://teampass.au/download)** or the [latest release](../../releases/latest).

| Platform | File |
|---|---|
| macOS 13+ (Apple silicon) | `TeamPass-mac-arm64.dmg` |
| macOS 13+ (Intel) | `TeamPass-mac-x64.dmg` |
| Windows 10+ (64-bit) | `TeamPass-win-x64.exe` |

Mac builds are signed and notarised by Apple. Each release lists SHA-256 checksums.

This repository holds release files only. Questions: support@memorecool.au
